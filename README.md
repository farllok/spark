One spark is all it takes: a macro match head the size of a planet, igniting a
world-sized solar flare that births a small ringed world in its core. Drawn as a
self-contained 1024x1024 SVG (layered ribbons, glow filters, grain), rendered once
in headless Chrome to `entry.png`, and handed in by a small Node program.

## Run it

```sh
node main.ts
```
